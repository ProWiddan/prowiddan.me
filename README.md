# ProWiddanOS

A personal portfolio website crafted to look and feel like the macOS desktop experience.

## Overview

ProWiddanOS is an interactive web-based portfolio that simulates a macOS-style operating system interface. Built entirely with vanilla HTML, CSS, and JavaScript, it presents professional information through familiar desktop metaphors like windows, a dock, and native-looking applications.

**Live Demo:** [prowiddan.me](https://prowiddan.me)

## Features

### System Interface

- **Boot Sequence** - Animated startup screen with progress indicator
- **Desktop Environment** - Fully rendered macOS-style desktop with icons and wallpaper
- **Menu Bar** - Functional application menu with dropdowns
- **Dock** - Animated application launcher with magnification effects
- **Launchpad** - Grid-style app launcher with search
- **Window Management** - Drag, resize, minimize, maximize, and close windows
- **Context Menus** - Right-click menus throughout the interface
- **Full Screen Mode** - Native browser fullscreen support

### Applications

| Application | Description |
|-------------|-------------|
| **Finder** | File browser with sidebar navigation, list/grid views, and search |
| **Safari** | Tabbed browser with URL bar and integrated contact page |
| **Notes** | Note-taking app with sidebar and multiple entries |
| **Terminal** | Interactive command-line interface for system info |
| **Settings** | System preferences for appearance, dock, wallpaper, and display |
| **Calculator** | Scientific calculator with full arithmetic functions |
| **Mail** | Email composer with social links |
| **Spotify** | Embedded Spotify player integration |
| **GitHub** | GitHub profile showcase |
| **Camera** | Webcam access module |
| **Calendar** | Monthly calendar widget |
| **Chess** | Playable chess game |

### Games

Built-in arcade collection:

- 2048
- Flappy Bird
- Tetris
- Snake

### Widgets

- **Calendar Widget** - Interactive monthly calendar with navigation
- **Discord Widget** - Real-time Discord presence via Lanyard API
- **Spotify Widget** - Currently playing track display

### Customization

- Multiple wallpaper options
- Dark mode (default)
- Dock positioning and sizing
- Transparency adjustments
- Accent color selection

### Gamification

Achievement system with unlockable badges:

- Hello World - Open your first application
- Power User - Explore 5 different apps
- Arcade Hobbyist - Try the game collection
- Grandmaster - Open the chess game
- Zen Master - Clear your desktop
- And more hidden achievements

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, flexbox, grid, animations
- **JavaScript** - Vanilla ES6+
- **External APIs**
  - Lanyard REST API - Discord presence
  - Spotify Embed API - Music playback
  - Unsplash - Wallpaper images

## Browser Support

Optimized for desktop browsers:

- Chrome (recommended)
- Firefox
- Safari
- Edge

Mobile devices receive a fallback page with contact links and a message to visit on desktop.
